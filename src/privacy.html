Nudge privacy policy

Nudge stores reminders in your user configuration folder and does not upload them. It has no account, analytics, advertising, or tracking.

Settings and diagnostics

Nudge saves reminder messages and settings in your user configuration folder. If Nudge cannot read or parse the settings file, it tries to move it aside as config.json.bad-* in the same folder. Each recovery copy can contain reminder text and stays there until you remove it. If the move fails, Nudge leaves the original in place. Changes to your reminder settings last only for that session. It keeps a copy of the chime in your cache. Local diagnostics hold counts, step names, and approximate durations for up to 20 launches. They exclude reminder text, paths, and device identifiers.

You can turn off recording in Settings under General. To remove your reminders, diagnostics, and cached chime, quit Nudge and delete its configuration and cache folders. On macOS these are the nudge folders under Library/Application Support and Library/Caches in your home folder. The Mac App Store version uses those folders inside its own container at ~/Library/Containers/com.weskcode.nudge/Data/Library/.

Deleting the configuration folder clears your diagnostics preference. Local recording starts again the next time you open Nudge.

Settings also remembers the last page and selected reminder ID in local web storage. Those choices can remain after you remove the folders. If you enabled Open at login, turn it off in General before quitting to remove the login registration.

The Mac App Store version gives the Nudge app permission to make outgoing network connections. Nudge includes this permission for WebKit. Settings and reminders load from bundled files.

Sharing a report

Review diagnostics shows the report before you copy it. Open GitHub issue opens GitHub in your browser. Its address contains no report. You decide whether to paste anything into GitHub. Submitted issues are public. The credit link also opens an external page in your browser.

Keyboard access on Mac

Input Monitoring is optional. While a reminder is showing, Nudge can check a key code and modifier flags to dismiss the reminder. It does not save or send keystrokes. You can turn off access in System Settings under Privacy & Security, Input Monitoring. You can still click Done.
