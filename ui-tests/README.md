# Screenshots

The images the main README shows, all captured on macOS 27 in dark mode at 2x.
Settings and the menu come from a debug build run with `HOME` pointed at a
temporary folder holding three sample nudges, so no real settings appear in
them. Pages were switched without synthetic keyboard or mouse input.

- `overlay-frosted-2026-09-30.png`: a reminder in the Frosted style with the
  Card layout, a break idea and a 20 second break. Frosted blurs the desktop
  behind it, and a window capture drops that blur, so this is a full display
  capture, cropped to remove the menu bar and the area below the card, then
  scaled to 2000 px wide. Nothing behind the blur is readable.
- `overlay-2026-09-30.png`: the same nudge in the Ocean style, showing a
  different break idea, cropped and scaled the same way.
- `settings-reminder-2026-10-05.png`: the Reminder page for a nudge using the
  eye symbol, the Forest style, the Ring layout and the Bloom animation. It is
  a window capture of a 1.0.7 release build run with `HOME` pointed at a
  temporary folder holding one sample nudge, with the window made taller so
  the Animation row shows.
- `settings-schedule-2026-09-30.png`: the Schedule page counting down to the
  next reminder.
- `tray-2026-09-30.png`: the menu bar menu with a countdown line for each of
  three nudges.
- `reminder-styles-2026-10-13.gif`: a 10 second clip of one Ring layout
  reminder with the Calm animation in each style (Frosted, Dusk, Ocean, Forest,
  Midnight), 2 seconds each, captioned with the style name.
- `reminder-animations-2026-10-13.gif`: a 10 second clip of one Forest style,
  Ring layout reminder with each animation (Calm, Bloom, Whisper), about 3
  seconds each, captioned with the animation name.

Both clips are full display recordings of a 1.0.7 release build run with
`HOME` pointed at a temporary folder holding one sample nudge. A plain
gradient window covered the desktop behind the reminder, each reminder opened
from Take a Break Now and closed on its own, the menu bar was cropped off and
the resting mouse pointer was painted out. They are 800 px wide at 15 frames
per second.

When the interface changes, replace these with new captures under the same
names and update the date in the file names and here.
